# 番頭さん 音声セリフ台本（収録用）

用途：VOICEVOX等で生成し、mp3として書き出してアプリに組み込む。
場面は2つ——**選択されたとき（名乗り）** と **仕事が終わったとき（完了）**。

## 収録・書き出しルール

- 1セリフ＝1ファイル。**2〜3秒以内**に収める（長いと毎回の操作でうるさく感じる）
- ファイル名は `{番頭ID}_{場面}.mp3`（下の表の通り）。実装指示書とファイル名を一致させること
- 書き出し形式：mp3 / モノラルで十分 / 音量は6人でそろえる（VOICEVOXなら音量スケール1.0で統一）
- VOICEVOX利用時はアプリのクレジット表記に「VOICEVOX:（話者名）」を記載すること（利用規約上の必須事項）

## 声のキャスティング方針（VOICEVOX話者選びの目安）

| 番頭 | 声の方向性 | 話速の目安 |
|---|---|---|
| はり出し番頭 | 張りのある中年男性。明るく請け負う | ふつう |
| 筆どめ番頭 | 落ち着いた静かな声。実直 | やや遅め |
| 触れ回り番頭 | 快活で通る声。呼び込み調 | やや速め |
| 暦番頭 | 穏やかで抑揚少なめ。淡々と正確 | 遅め |
| 火消し番頭 | 低くて力強い。歯切れよく | 速め・歯切れ重視 |
| 蔵番頭 | 年配の柔らかい声。ゆったり | 一番遅め |

※高齢ユーザーが聞き取りやすいよう、全員**話速は標準〜遅め寄り**、極端な演技より聞き取りやすさ優先。

## セリフ設計の意図（変更するときの指針）

- 名乗りは必ず**「名前＋役目＋請け負いの言葉」**の3点構成。初めての人でも「誰が・何をしてくれるか」が音だけでわかる
- 完了は**短く安心させる言葉**で終える（「ご安心ください」「お確かめください」）。次の操作を促す指示は音声に入れない（画面側のボタンが担当）
- 「アップロード」「生成」「AI」などのIT用語は音声にも一切使わない（AIを隠す設計と同じ原則）
